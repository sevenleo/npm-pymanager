# Plano: Corrigir bug numérico + limpeza de código

## Bugs e melhorias encontrados

### BUG 1 (crítico) — Entrada numérica multi-dígito
`getch()` lê 1 caractere. Digitar `10` lê `1` e processa como pacote 1 antes de ler `0`.

### BUG 2 (limpeza) — Import morto
`import shutil` (linha 7) nunca é usado. Remover.

### BUG 3 (consistência) — Mensagem de erro inconsistente
O branch `else` atual usa `t("invalid_option")` para número inválido. Deveria usar `t("invalid_number")` para ser consistente com o branch `o`.

            if ch == "\n" or ch == "\r":

            num_str += ch
        print()
        try:
            num = int(num_str.strip())
            row = next(r for r in rows if r["id"] == num)
            update_one(row)
