Trust

What it runs, exactly

  • Reads npm list/outdated --depth=0 --json, local + global
  • Writes npm update on outdated rows only (exit 0 = ok)
  • Asks (y/N) before update-all; timeouts warn, offline keeps data

On disk

node_modules + lock move within your ranges; package.json untouched. Review git diff package-lock.json, undo with checkout + npm ci.

FAQ

Details, tucked away

Will it break my project?

It follows your package.json ranges via npm update — never forces @latest. Commit first; undo with git checkout -- package-lock.json + npm ci.

What gets updated?

Only outdated rows — locals first, then globals [L]/[G]. Anything but y aborts update-all.

Workspaces? pnpm? Globals need sudo?

Plain npm only — run once per workspace. Same rights as npm update -g; pre-check npm root -g.

Offline? Tune? Small screen?

Offline: latest stays empty, last data kept. Tune: NPM_PM_TTL 120, TIMEOUT 90, UPDATE_TIMEOUT 300, ASCII/NO_COLOR. Display: full ≥80, compact 60–79, cards below 60.

Sizes? Languages? Peek first?

Sizes from disk, cached per scope + version. UI: locales/en,pt,es.json. Peek: python main.py --test (fake data).
